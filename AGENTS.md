# LifeOS development

Keep modules small and domain logic independent of React. Prefer simple implementations to speculative abstractions. Use strict TypeScript and validate all external inputs. Never expose secrets or bypass Supabase RLS. Never present sample data as real user activity. Test changed business logic. Preserve user records during migrations; use versioned migrations and tombstones. Document major decisions. Do not add paid AI dependencies or commercial/SaaS features. Reminders are critical: browser timers never substitute for the native queue. Keep desktop idle work small. Never claim unverified behavior works. Do not push, deploy, or enable Windows startup without explicit user choice. Keep Turkish copy centralized. Native and cloud changes require their own verification; frontend tests do not prove either.
